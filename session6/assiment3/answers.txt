Error 1: font-size unit on h2
Line: .course-card h2 { font-size: 1.5em; }
em is follow the parent font-size (.course-card = 20px), so 1.5em = 30px.
Fix: font-size: 1.5rem; (rem is relative to :root = 16px)
Computed after: 24px

the variable name is wrong.

Error 3: action hover
Line: .action :hover { color: #6845a8; }
the space makes it a descendant selector, so it targets hovered elements inside .action, not the link itself.
Fix: .action:hover
